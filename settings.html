Tally Prime connection

Machine where Tally Prime is running, e.g. localhost or 192.168.1.20.
Enter a host name or IP address.
Port must be 1–65535.

Enable the Tally HTTP server

  1. In Tally Prime press F1 (Help) → Settings → Connectivity.
  2. Open Client/Server configuration.
  3. Set TallyPrime acts as to Both (or Server).
  4. Set Port (default 9000), then accept and restart Tally.
  5. Open the company you want to work with; the company is chosen on the Import and Ledgers pages.
